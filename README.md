# Pin Chien Technology Leadership Advisory

Static English website ready for GitHub Pages.

## Files
- `index.html` - homepage, services, FAQ, process and CTA
- `terms.html` - terms, rescheduling and refund policy
- `privacy.html` - privacy and personal data notice
- `styles.css` - responsive aqua-blue visual system
- `script.js` - mobile navigation, service selection and email CTA
- `README.md` - deployment and launch checklist

## GitHub Pages deployment
1. Upload all six files to the repository root.
2. Open Settings > Pages.
3. Choose Deploy from a branch.
4. Select `main` and `/ (root)`.
5. Save and test the published URL on desktop and mobile.

## Before commercial launch
Search the repository and replace all placeholders including `your-email@example.com`, `[TO BE COMPLETED]`, `[IF APPLICABLE]`, and `[LEGAL NAME TO BE COMPLETED]`. Confirm tax/invoice treatment, payment method, data retention, actual Microsoft/cloud/AI tools, and legal review.
